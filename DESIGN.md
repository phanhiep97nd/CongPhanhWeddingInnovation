# Design tokens

The invitation is the visual source for every page. The landing page uses its photograph, script signature, warm paper surface, and botanical green text. Account and editing screens keep the same palette with quieter layouts.

| Token | Value | Use |
| --- | --- | --- |
| Paper | `#fdf5f6` | Page background |
| Blush | `#f9e8ea` | Soft sections and selected controls |
| Rose | `#f2c8cd`, `#c9848b`, `#a85e65` | Invitation accents and actions |
| Green | `#4c6635`, `#8da06b` | Text and secondary details |
| Display | Cormorant Garamond | Large headings |
| Body | Plus Jakarta Sans | Controls and prose |
| Invitation | Noto Serif, Great Vibes | Names and signature |
| Radii | 12–16px for controls, 24px for invitation panels | Rounded paper surfaces |
| Spacing | 8px base rhythm; 24–48px between content groups | Forms and sections |
| Motion | 0.75–0.9s easing `[0.22, 1, 0.36, 1]` | Invitation reveals and hero; reduced motion disables movement |

Each wedding supplies `theme.primary` for its invitation accent. Browser selection, focus rings, caret, and scrollbars use the same palette.
